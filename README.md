
# 🚀 Jenga Tech --- 50 Projects in 50 Days Challenge

**50 Days. 50 Projects. One Stronger Developer.**

Welcome to the **Jenga Tech 50 Projects in 50 Days Challenge**, a
practical software development program designed to help developers build
**discipline, consistency, problem-solving skills, and a strong coding
habit** through daily project development.

📅 **Start Date:** October 1, 2026\
🏢 **Organized by:** Jenga Tech Software Engineering Department

------------------------------------------------------------------------

## 🎯 Challenge Goal

The goal is simple:

> **Stop only taking tutorials. Start building.**

For **50 consecutive days**, participants will build one project each
day, progressing from basic frontend development to backend systems,
databases, APIs, and complete full-stack applications.

By Day 50, participants should have:

-   50 completed projects
-   A stronger GitHub profile
-   Improved HTML, CSS, and JavaScript skills
-   Backend and database experience
-   Experience working with APIs
-   Better debugging and problem-solving skills
-   A portfolio of real projects
-   Greater confidence building software independently

# ⚙️ Getting Started

## 1. Follow the GitHub Account

Follow **DevRolec** for challenge updates:

https://github.com/DevRolec

## 2. Fork the Repository

Official repository:

https://github.com/DevRolec/50-Projects-in-50-Days-Challenge

Click **Fork → Create Fork**.

## 3. Clone Your Fork

``` bash
git clone https://github.com/YOUR-USERNAME/50-Projects-in-50-Days-Challenge.git
cd 50-Projects-in-50-Days-Challenge
code .
```

Replace `YOUR-USERNAME` with your GitHub username.

## 4. Configure Git

``` bash
git config --global user.name "Your Full Name"
git config --global user.email "yourgithubemail@gmail.com"
```

Use the email connected to your GitHub account.

## 5. Add the Official Repository as Upstream

``` bash
git remote add upstream https://github.com/DevRolec/50-Projects-in-50-Days-Challenge.git
git remote -v
```

# 🔄 Daily GitHub Workflow

After completing your daily project:

``` bash
git add .
git commit -m "Day 01: Personal Profile Page"
git push origin main
```

Change the day number and project name appropriately each day.

# 📄 Project Documentation

Every project should contain a `README.md` explaining:

-   Project name
-   Project description
-   Features
-   Technologies used
-   How to run the project
-   What you learned
-   Challenges encountered

Your code should be organized, readable, tested, and understandable.

# ⚠️ Challenge Rules

-   ✅ Build **one project every day**
-   ✅ Push your project to GitHub daily
-   ✅ Update your README
-   ✅ Test your project before pushing
-   ✅ Use meaningful commit messages
-   ✅ Attend scheduled online sessions
-   ✅ Understand every piece of code you submit
-   ✅ Submit through Google Classroom when requested
-   ❌ Do not copy another student's project
-   ❌ Do not submit code you cannot explain
-   ❌ Do not wait until the end to upload multiple projects

AI tools may be used to **assist learning, debugging, research, and
development**, but they should not replace your understanding.

# 🧠 The Developer Mindset

Some projects will be easy. Some will frustrate you. You will encounter
bugs, and you will sometimes get stuck.

**That is part of becoming a software developer.**

Developers improve by:

**Building → Failing → Debugging → Researching → Fixing → Rebuilding**

Don't compare yourself with another developer. Compare yourself with the
developer you were yesterday.

By Day 50, the goal is for you to confidently say:

> **"Give me the requirements. I can build it."**
